색상

Primitive 팔레트(hex 원시값)와 Theme 일반 시맨틱 44개(surface·text·border·bds-icon·brand·accent, Default·Dark 2모드)입니다. 컴포넌트별 토큰(button·chip·tabs 등 246개)은 각 컴포넌트 문서 페이지를 참조하세요. 컴포넌트는 이 값을 직접 쓰지 않고 var(--*) CSS 커스텀 프로퍼티를 통해 참조합니다.
