한 열만 늘어나고 나머지는 고정 폭입니다 — 고정 열의 셀에만 flex: 0 0 <폭>을 주고 늘어나는 열(여기서는 이메일)은 기본값을 그대로 둡니다. 전부 고정하면 표가 컨테이너보다 좁을 때 오른쪽에 빈 공간이 남습니다.
