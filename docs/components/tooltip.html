Tooltip & Help Icon

Tooltip: Theme(light/dark) × Arrow(none/top/bottom/left/right) 조합입니다. Help Icon: 아이콘 + Tooltip 조합이며, 대표 Arrow만 표시합니다(풀 매트릭스 아님).

Tooltip

_tooltip.scss에 실제로 정의된 arrow 클래스는 tooltip-arrow-none/top/bottom/left/right뿐입니다. Figma 축에 있는 bottom-left/bottom-right(코너 오프셋)는 대응하는 CSS 클래스가 아직 없어 이 페이지에서는 제외했습니다 — 추정으로 만들지 않습니다. Theme=dark/light는 사이트 다크모드가 아니라 컴포넌트 자체의 고정된 스타일(어두운 배경 스타일 / 밝은 배경 스타일)입니다 — 사이트를 다크모드로 바꿔도 이 배경·글자색은 반전되지 않습니다. bds-tooltip-light는 배경·글자·보조 텍스트가 전부 완전히 고정이고, bds-tooltip-dark는 배경과 제목 글자는 고정이지만 보조 텍스트(fg-supporting)만 사이트 다크모드에서 대비를 낮춘 색으로 바뀝니다 — 이 페이지는 라이트 테마로 고정돼 있어 그 차이는 보이지 않습니다.

Help Icon

_help-icon.scss는 .bds-tooltip을 :hover/:focus에서만 display:flex로 보여줍니다. 정적 문서에서는 상호작용을 재현할 수 없어 .bds-tooltip 엘리먼트에 인라인 style="display:flex; position:static;"를 직접 얹어 강제로 표시했습니다. 또한 _help-icon.scss 자체는 테마를 고정하지 않습니다(어떤 .bds-tooltip-light/.bds-tooltip-dark를 조합할지는 사용하는 쪽 자유) — 아래 예시는 관례적으로 bds-tooltip-dark를 사용했습니다. Figma의 Property 축(top-left/top-right/top-no-arrow 포함)도 Tooltip 쪽 arrow 클래스와 1:1로 대응하지 않아, 실제 존재하는 클래스만으로 대표(top/bottom/right)만 나열합니다.
