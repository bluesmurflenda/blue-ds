Tooltip & Help Icon

Tooltip: Theme(light/dark) × Arrow × Supporting(text/list). light에는 화살표가 없습니다 — 대신 테두리가 있습니다. Help Icon: 아이콘 + Tooltip 조합이며 대표 Arrow만 표시합니다(풀 매트릭스 아님).

Theme × Arrow

Theme=dark/light는 사이트 다크모드가 아니라 컴포넌트 자체의 고정된 스타일(어두운 배경 스타일 / 밝은 배경 스타일)입니다 — 사이트를 다크모드로 바꿔도 이 배경·글자색은 반전되지 않습니다. bds-tooltip-light는 배경·글자·보조 텍스트가 전부 고정이고, bds-tooltip-dark는 배경과 제목은 고정이지만 보조 텍스트(fg-supporting)만 사이트 다크모드에서 대비를 낮춘 색으로 바뀝니다 — 이 페이지는 라이트 테마로 고정돼 있어 그 차이는 보이지 않습니다. light은 Arrow=none 하나뿐이라 화살표 엘리먼트를 두지 않습니다. 예전 마크업에 남아 있는 .bds-tooltip__arrow는 배경색을 못 받아 보이지 않습니다. Figma 축에 있는 bottom-left/bottom-right(코너 오프셋)는 대응하는 CSS 클래스가 아직 없어 제외했습니다 — 추정으로 만들지 않습니다.

Supporting

보조 텍스트가 문단이냐 글머리표 목록이냐를 가르는 축입니다. 클래스가 아니라 태그로 가릅니다 — <p class="bds-tooltip__supporting">이면 문단, <ul class="bds-tooltip__supporting">이면 목록입니다. 툴팁 폭은 내용이 정합니다(max-width: 320px) — 아래 두 칸의 폭이 다른 이유입니다.

Help Icon

_help-icon.scss는 .bds-tooltip을 :hover/:focus에서만 display:flex로 보여줍니다. 정적 문서에서는 상호작용을 재현할 수 없어 .bds-tooltip 엘리먼트에 인라인 style="display:flex; position:static;"를 직접 얹어 강제로 표시했습니다. 실제 컴포넌트에서 툴팁은 position:absolute라 16×16 아이콘 상자 밖에 떠 있지만, 강제로 흐름 안에 넣으면 그 상자 폭에 눌립니다 — 그래서 아래 예시는 아이콘 상자에도 width:auto; height:auto;를 얹었습니다. 또한 _help-icon.scss 자체는 테마를 고정하지 않습니다(어떤 .bds-tooltip-light/.bds-tooltip-dark를 조합할지는 사용하는 쪽 자유) — 아래 예시는 화살표가 있는 bds-tooltip-dark를 사용했습니다. Figma의 Property 축(top-left/top-right/top-no-arrow 포함)도 Tooltip 쪽 arrow 클래스와 1:1로 대응하지 않아, 실제 존재하는 클래스만으로 대표(top/bottom/right)만 나열합니다.
