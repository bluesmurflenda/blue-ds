폼 컴포넌트 / Input

Input

라벨 + 필드(선행 아이콘 슬롯 + <input>) + 힌트로 구성되며, 시맨틱(field/*)은 Select·Dropdown·Textarea와 공유합니다.

Size × Validation

filled(값이 채워진 상태)는 border/bg가 normal과 동일합니다 — 실제 <input>을 쓰므로 ::placeholder로 자연히 구분되고 별도 클래스가 없습니다.

Disabled

검증 상태별로 확인합니다(md 사이즈). .bds-input-disabled를 검증 modifier와 함께 사용하며, 힌트 텍스트가 흐려집니다.

선행 아이콘 슬롯

.bds-input__icon. 사이드바 검색창(docs/assets/nav.js)이 쓰는 실제 조합입니다.

Field/Group

필드 앞뒤에 버튼이나 아이콘 버튼을 붙입니다. 클래스는 bds-field-group 하나뿐입니다 — 사이즈는 안에 들어가는 bds-input-{size}·bds-btn-{size}가, 애드온 위치는 자식 순서가, 종류는 bds-btn이냐 bds-icon-btn이냐가 정합니다.
