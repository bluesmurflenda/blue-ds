Dropdown & Select

Dropdown

트리거를 눌러 직접 열고 닫을 수 있습니다. 상태는 트리거의 aria-expanded와 패널의 hidden 속성 둘로만 표현합니다 — 디자인시스템은 CSS만 배포하므로 토글 스크립트는 이 페이지에 있습니다(사이드바·Accordion과 같은 방식). md는 열어 둬서 닫힘·열림을 한 화면에서 비교할 수 있습니다. 옵션 상태는 default/selected(.bds-list-item-selected)/disabled(.bds-list-item-disabled)입니다.

패널은 트리거를 덮지 않고 아래에 흐름대로 쌓입니다(.bds-dropdown이 세로 flex). Figma 조립 예시도 같은 모양입니다.

Select — Size × Validation

라벨 + 필드(콘텐츠 텍스트 + chevron) + 힌트로 구성. 패널·옵션은 Dropdown의 .bds-list-panel/.bds-list-item을 재사용합니다.

Select — Disabled

검증 상태별로 확인합니다(md 사이즈). .bds-select-disabled를 검증 modifier와 함께 사용합니다.

Select — 선행 아이콘 슬롯

.bds-select__icon — .bds-select__chevron과 나란히 필드 안에 놓이는 선택적 슬롯입니다(사이즈와 무관하게 고정 크기입니다).
