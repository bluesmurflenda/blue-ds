Button

변형은 primary/secondary/tertiary/outline/ghost/danger/scrim-dark/scrim-light/link입니다. 사이즈는 sm/md/lg/xl이며, xs는 ADR-015로 제외했습니다(실사용 없음). 아래 「State」처럼 bds-btn-{state} 클래스를 붙이면 마우스를 올리지 않고도 상태별 모습을 볼 수 있습니다 — 그래서 변형 표는 default만 나열합니다.

Variant × Size (default)

scrim-dark/scrim-light은 배경 위에서만 의미가 있어 각각 어두운/밝은 배경 위에 올렸습니다.

sm md lg xl

State

상태 클래스는 해당 pseudo-class와 같은 규칙에 묶여 있어 모습이 똑같습니다. 모습만 바꿉니다 — 실제로 못 누르게 하려면 disabled 속성이나 aria-disabled를 함께 써야 합니다. 여기 있는 disabled 칸은 클래스만 붙인 것이라 눌립니다.

Disabled

모든 변형 공통 톤(link 제외 — link는 자기 전용 fg-disabled 토큰).

Icon 조합

Icon Left/Right 슬롯 — <svg>를 라벨 앞뒤에 배치합니다.

ButtonGroup

버튼을 붙여 한 덩어리로 씁니다. 사이즈는 항목의 bds-btn-{size}가 정하고, 바깥 모서리만 둥글게 남습니다. 항목 사이 구분선은 border-right로 그려 별도 마크업이 없습니다.
