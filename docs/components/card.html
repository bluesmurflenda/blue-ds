Card

hover(border-hover 등장)는 정적 페이지로 재현할 수 없는 상호작용 상태라 제외합니다.

Orientation × Style

Default=box-shadow만, Outline=card/border 보더, Tinted=card/bg-tinted 배경(보더·섀도 없음) — 컴포넌트 설명에 명시된 Style 구분입니다.

Orientation — Horizontal

가로형은 미디어가 160px 고정이라 좁은 칸에 넣으면 본문이 잘립니다. 한 줄에 하나씩 두고 폭을 다 쓰게 합니다.

State — Disabled

.bds-card-disabled — 투명도를 낮추고 pointer-events: none을 적용합니다. Style 축과 독립적으로 적용됩니다.
