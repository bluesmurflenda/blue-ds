Header

Theme(light/dark) × Surface(solid/floating)의 조립 예시(공지 배너 + 로고 + 네비 메뉴 + 우측 액션)입니다. 개별 클래스를 격자로 나열하기보다 실제 조합을 보여주는 조립형 컴포넌트라 대표 조합별로 전체 헤더를 나열했습니다. Surface=floating은 반투명 배경(nav/bg-floating) + 블러 효과로, 콘텐츠 위에 겹쳐 쓰는 플로팅 헤더용입니다(.bds-site-header-floating — Theme 클래스와 함께 씁니다).

조립 예시 — Light

bds-site-header-light — 흰 배경 + 얇은 하단 보더. nav 아이템은 hover/selected 시 브랜드 블루(bds-is-selected)로 바뀝니다.

신규 버전 출시 안내 — 대시보드 UI가 개선되었습니다.
홈 제품 고객사례 문의

조립 예시 — Dark

bds-site-header-dark — 어두운 배경입니다. 실측 결과 이 배경 위 nav 아이템은 default/hover/selected 글자색이 모두 흰색으로 동일해, bds-is-selected를 줘도 시각적으로 구분되지 않습니다(실측값 그대로 반영).

신규 버전 출시 안내 — 대시보드 UI가 개선되었습니다.
홈 제품 고객사례 문의

조립 예시 — Floating(Surface)

bds-site-header-light bds-site-header-floating — 콘텐츠 위에 겹쳐 배치해 반투명 + 블러 효과가 보이도록 그라디언트 배경 위에 올렸습니다. 보더는 solid와 동일하게 유지됩니다.

홈 제품 고객사례

조립 예시 — Dark + Floating(Surface)

bds-site-header-dark bds-site-header-floating — &-dark.site-header-floating 전용 규칙으로 반투명 배경이 nav-dark-bg-floating으로 바뀝니다. Light+Floating과 같은 블러가 적용되되 배경이 어둡습니다.
