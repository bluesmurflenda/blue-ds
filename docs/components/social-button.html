Social Button

사이즈는 sm/md/lg/xl이며 클래스를 안 붙이면 lg입니다. 로고 크기가 label형(16/16/20/20)과 icon형(18/20/24/24)에서 따로 놉니다. 로고는 스프라이트에 실제 브랜드 마크가 없어 placeholder 아이콘(message-circle/smile/globe)을 사용합니다.

Naver / Kakao / Apple — Brand × Outline × Type

brand는 소셜별 브랜드색 배경, outline은 3사 공통(흰 배경 + 회색 보더) — 로고만 다릅니다.

Google

별도 브랜드 테마가 없어 outline과 동일 규칙(.bds-social-btn-outline, .bds-social-btn-google)을 공유합니다.

Size

한 행에 사이즈 축이 통째로 들어갑니다. 높이는 32/40/48/56이고 label형은 좌우 여백이 btn/padding-x/{size}를 따릅니다 — lg가 20에서 24로 바뀌었습니다. icon형은 높이와 같은 폭의 정사각입니다.

smmdlgxl

Disabled

소셜·테마와 무관하게 공통 톤입니다 — 배경 btn/disabled/bg, 글자 btn/disabled/fg, 테두리 btn/disabled/border. 브랜드 로고는 색을 바꿀 수 없어 opacity: 0.4로 낮춥니다(Figma에도 토큰이 아니라 직접 적은 값입니다).
