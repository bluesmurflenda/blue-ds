Social Button

Disabled 축 자체가 없는 컴포넌트라(hover는 검정 오버레이일 뿐) default 상태만 나열합니다. 로고는 스프라이트에 실제 브랜드 마크가 없어 placeholder 아이콘(message-circle/smile/globe)을 사용합니다.

Naver / Kakao / Apple — Brand × Outline × Type

brand는 소셜별 브랜드색 배경, outline은 3사 공통(흰 배경 + 회색 보더) — 로고만 다릅니다.

Google

별도 브랜드 테마가 없어 outline과 동일 규칙(.bds-social-btn-outline, .bds-social-btn-google)을 공유합니다.
