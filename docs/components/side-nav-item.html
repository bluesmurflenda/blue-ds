Side Nav Item

hover는 매트릭스에서는 제외했습니다(Type 축과 조합하면 표가 지나치게 커짐). 배지 슬롯(.bds-side-nav-item__badge)은 별도로 시연합니다. 이 문서 사이트의 왼쪽 사이드바 자체가 이 컴포넌트(bds-side-nav-item-light)의 실제 사용 예시입니다.

Type × Theme × State 매트릭스

dark 테마는 hover/selected 배경이 brand 계열로 실측되어, 그보다 어두운 var(--bds-blue-900) 배경 위에 올려 자연스러운 밝기 단계를 보여줍니다. light 테마는 흰 배경 위에 올렸습니다.

Hover — light/dark 비대칭

아래 항목에 실제로 마우스를 올려 확인하세요(인라인 스타일로 흉내낸 것이 아니라 :hover CSS를 그대로 씁니다). light는 배경과 글자·아이콘 색이 함께 nav-fg-hover로 바뀌지만, dark는 배경만 바뀌고 글자·아이콘 색은 흰색 그대로 고정입니다(_side-nav-item.scss의 light/dark 규칙 참고).

Badge 슬롯

.bds-side-nav-item__badge는 콘텐츠 우측에 배치되는 카운트 슬롯입니다(.bds-side-nav-item의 justify-content: space-between이 좌우로 밀어냅니다).
