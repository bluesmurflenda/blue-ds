Tabs

hover는 정적 페이지로 재현할 수 없는 상호작용 상태라 제외하고, 클래스·속성으로 켤 수 있는 상태만 나열합니다. 텍스트는 전 타입 공통으로 사이즈별로 스케일합니다 — sm은 Body/Sm, md·lg는 Body/Lg, xl은 Body/Xl입니다. Size는 여기에 더해 패딩·높이도 바꿉니다.

Underline

.bds-tabs-item-underline — 내부 .bds-tabs-item__content(레이블) + .bds-tabs-item__underline(하단 밑줄 바) 구조가 필수입니다.

Underline (Brand)

.bds-tabs-item-underline-brand — 구조는 underline과 동일, selected 색만 브랜드 블루로 바뀝니다.

smmdlgxl

Pill

.bds-tabs-item-pill — 내부 슬롯 구조 없이 텍스트만 직접 넣습니다.

smmdlgxl

Segmented

.bds-tabs-item-segmented — 트랙 배경·보더를 담당하는 .bds-tabs-segment 컨테이너로 감싸야 정상적으로 보입니다.
