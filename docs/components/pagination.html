Pagination

hover는 정적 페이지로 재현할 수 없어 제외합니다.

Number 셀 프리미티브

.bds-pagination-number(원형)와 .bds-pagination-number-square(사각형, button-group 전용)는 모든 Type이 공유하는 셀입니다. 사이즈는 조상 요소의 .bds-pagination-{size}가 결정합니다. 사각 셀 자체에는 테두리가 없습니다 — 칸을 가르는 선은 button-group이 긋습니다.

Type = numbers

아이콘만 남은 Prev/Next + 번호를 가운데로 모읍니다. Prev/Next는 번호 셀과 같은 크기의 정사각(.bds-pagination__nav)이고, 이름이 보이지 않으므로 aria-label로 답니다. .bds-pagination-numbers.bds-pagination-{size} 조합.

Type = simple

"Page N of M" 텍스트 + Prev/Next 버튼(.bds-btn .bds-btn-outline 재사용). .bds-pagination-simple.bds-pagination-{size} 조합.

Type = simple-icon

아이콘 전용 Prev/Next(.bds-icon-btn .bds-icon-btn-outline 재사용) + "Page N of M". 화살표 색은 아이콘 버튼이 그대로 내는 btn/outline/fg입니다. 테이블 하단 페이지네이션도 이 클래스를 재사용합니다. .bds-pagination-simple-icon.bds-pagination-{size} 조합.

Type = numbers-buttons

Prev/Next는 독립 아이콘 버튼(.bds-icon-btn .bds-icon-btn-outline), 번호는 numbers와 같은 낱개 둥근 셀(.bds-pagination__numbers)입니다. 테두리로 붙은 사각 그룹은 button-group뿐입니다. 화살표 색은 simple-icon과 같습니다(btn/outline/fg).

Type = button-group

Prev/Next까지 번호와 함께 .bds-pagination-group.bds-pagination-{size} 하나의 테두리 그룹에 묶입니다. Prev/Next는 아이콘만 남은 .bds-pagination__nav이고 좌우 여백이 사이즈마다 다릅니다. 칸을 가르는 선은 두 번째 칸부터 왼쪽에 하나씩 들어가며, 바깥 반경은 sm만 한 단계 작습니다.

Pagination Compact(모바일)

Prev/Next 아이콘 버튼(.bds-pagination-compact__nav, 고정 크기, 사이즈 축 없음) + 번호 나열. .bds-pagination-compact__numbers에는 전용 숫자 셀 클래스가 없어 .bds-pagination-number를 그대로 재사용하며, 크기를 맞추기 위해 .bds-pagination-sm을 함께 얹었습니다. 화살표 색은 Pagination과 달리 btn/ghost/fg입니다.
