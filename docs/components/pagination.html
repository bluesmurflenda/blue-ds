Pagination

hover는 정적 페이지로 재현할 수 없어 제외합니다.

Number 셀 프리미티브

.bds-pagination-number(원형)와 .bds-pagination-number-square(사각형, numbers-buttons·button-group 전용)는 모든 Type이 공유하는 셀입니다. 사이즈는 조상 요소의 .pagination-sm/md/lg가 결정합니다.

Type = numbers

테두리 없는 텍스트 Prev/Next + 번호. 위쪽 구분선(border-top). .bds-pagination-numbers.pagination-{size} 조합.

Type = simple

"Page N of M" 텍스트 + Prev/Next 버튼(.bds-btn .bds-btn-outline 재사용). .bds-pagination-simple.pagination-{size} 조합.

Type = simple-icon

아이콘 전용 Prev/Next(.bds-icon-btn .bds-icon-btn-outline 재사용) + "Page N of M". 테이블 하단 페이지네이션도 이 클래스를 재사용합니다. .bds-pagination-simple-icon.pagination-{size} 조합.

Type = numbers-buttons

Prev/Next는 독립 버튼(.bds-btn .bds-btn-outline), 번호만 .bds-pagination-group.pagination-{size}로 테두리 그룹에 묶입니다.

Type = button-group

Prev/Next까지 번호와 함께 .bds-pagination-group.pagination-{size} 하나의 테두리 그룹에 묶입니다. Prev/Next는 .bds-pagination__nav(아이콘+텍스트).

Pagination Compact(모바일)

Prev/Next 아이콘 버튼(.bds-pagination-compact__nav, 고정 크기, 사이즈 축 없음) + 번호 배지. .bds-pagination-compact__numbers에는 전용 숫자 셀 클래스가 없어 .bds-pagination-number를 그대로 재사용하며, 크기를 맞추기 위해 .bds-pagination-sm을 함께 얹었습니다.
