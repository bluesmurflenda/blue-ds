평일 셀 위에 .bds-calendar-day 모디파이어를 하나씩만 올린 레퍼런스입니다.

상태 × 요일유형 매트릭스

is-empty는 요일유형과 무관하게 항상 빈 칸이라 위 showcase에서만 다룹니다. State와 요일유형(Day) 색이 같이 걸릴 때 우선순위가 갈립니다 — default·today·available은 토/일에서 Day 색이 이기고(여전히 파랑/빨강으로 보임, 평일은 각 State 색을 씁니다 — available은 cell/available-fg), selected·past·unavailable은 State 색이 이깁니다(토/일이어도 State 색으로 덮입니다). 아래 매트릭스에서 토·일 열을 보면 이 차이를 확인할 수 있습니다.

조립 예시 — 2026년 8월

Type=Card(.bds-calendar-card). 8/1~27은 is-past, 8/28(금)은 is-today, 8/29(토)는 is-available, 8/30(일)은 is-unavailable, 8/31(월)은 is-selected로 구성했습니다. 이전/다음 달 버튼은 bds-icon-btn bds-icon-btn-sm bds-icon-btn-ghost를 재사용합니다.
